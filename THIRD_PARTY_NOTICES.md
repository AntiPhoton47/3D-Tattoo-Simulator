- License: [Creative Commons Zero v1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)

Innerscene identifies the model as adapted from MakeHuman CC0 assets and releases it under CC0. MakeHuman's official license page likewise states that its core graphical assets are CC0. Attribution is not required by CC0, but these credits are retained for provenance and reproducibility.

## Expanded MakeHuman community library

`appearance-catalog.js`, `assets/appearance-library/` and `assets/appearance-textures/` contain optimized geometry and diffuse materials generated from 28 MakeHuman community asset packs: Bodyparts 04–06, Dress 01–02, Eyebrows 01, Eyelashes 01, Glasses 01–02, Gloves 01, Hair 01–02, Hats 03, Pants 01–02, Shirts 01–03, Shoes 01–03, Skirts 01–02, Underwear 01–04 and the eyes in MakeHuman System Assets. The catalog records each item's author, license, original source page, intended body compatibility and originating pack.

The collection contains both **CC0** and **CC-BY** works. CC-BY author and source records have been retained from the supplied pack metadata and must remain with redistributed builds. The build preserves positions, triangulated faces, UV seams, three-point MakeHuman proxy weights, signed proxy offsets, body-scale references, available `delete_verts` masks and source material parameters. Referenced diffuse images are resized to a maximum dimension of 512 pixels for the web bundle; unreferenced pack files are not redistributed.

`anatomy-targets.js` contains sparse target deltas and quantized hm08 source coordinates generated from the supplied CC0 Cheek 01, Ears 01 and Nose 01 target packs. These coordinates support bounded high-resolution anatomical fields in the application; the source archives and base mesh are not redistributed.

`base-vertex-map.js` was generated against the official CC0 hm08 [`base.obj`](https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/makehuman/data/3dobjs/base.obj) at commit `a8bc2d54ff0ac92e78ff71431b1023eda42bf482`. It contains only index maps, not a redistributed copy of the source mesh.

- CC0 terms: [Creative Commons Zero v1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- CC-BY terms: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)

## MakeHuman pose adaptations

`pose-presets.js` contains limb-control adaptations generated from 117 BVH poses in the supplied MakeHuman System Poses and Poses 01–05 packs. The source metadata identifies these pose packs as CC0. The application exposes a curated subset in its unified pose menu and uses the source limb configurations to guide its shoulder-elevation correction. It transfers only shoulder elevation/forward motion, upper-arm twist, elbow flexion and knee flexion; it does not redistribute the original BVH files or represent the adaptations as exact full-body retargets.

## Project-authored sample motifs
